# 没有被征服的

> 米游社词条 3688，抓取于 2026-10-30

任务名

	

没有被征服的

任务地区

	

匹诺康尼

任务类型

	

开拓任务

开放等级

	

34

任务描述

	

「秩序」的美梦已经破裂，星穹列车在匹诺康尼的开拓之旅终于告一段落。家族邀请列车组众人前往空中飞艇「晖长石号」参与重要会谈，两位星核猎手也在梦境的一角复盘他们此次的「演出」。

奖励

	

里程*200、星琼*30、漫游指南*4、金表钞*100、信用点*20000

交互对话

三月七：醒醒…醒醒……

三月七：…喂，开拓者！别睡啦，太阳晒屁股啦——

三月七：你没事吧，听得清我说话吗？我听房间里一点动静都没有，快吓死了。

我这是在做梦吗？
好熟悉的对话…
小题大做了吧。

三月七：不是在做梦啦，这是在现实，「白日梦」酒店！「秩序」的美梦已经结束了。

三月七：虽然已经过去一天了，但回想起来还是汗流浃背，列车的「开拓」之旅差点就要交代在这匹诺康尼了……

三月七：你倒是心宽，还能呼呼大睡。我可是留下了心理阴影，昨晚连眼睛都不敢闭，生怕一睡着就再也醒不过来了。

星核怎么样了？
其他人在哪里？
会有黑眼圈的。

三月七：你睡着的这段时间，星核已经被封印了。匹诺康尼的普通民众完全不知道发生了什么，他们只觉得记忆有些模糊，像是被人抽空了一段。

三月七：家族对外的说法是「谐乐大典遭遇来历不明的星核袭击，被迫中止」——毕竟「秩序」的事怎么也没法摆到台面上讲嘛。

三月七：现在，橡木以外的四大家系正在尽力平息事件余波。列车组也受到邀请，去家族的「晖长石号」上一坐，以见证人的身份参与重要会谈。

三月七：现在就差你了，赶紧收拾收拾。准备好了，咱们就出发！

与三月七交谈，准备出发

三月七：呼，经历了这一切，感觉没什么比平平安安的现实更好了……

「晖长石号」是？
再讲讲匹诺康尼的现状…
你在太一之梦里遭遇了什么？
出发去找大家吧。
还有别的事要做。

三月七：是一艘巨大的空中飞艇，可厉害了！听说它从来不在公众前露面，只有家族的贵客才有资格登上船首，一览匹诺康尼的美丽风光。

三月七：鸢尾花家系还派人送来了好多纪念品和果篮，还有一个精致的按钮模型，等你好利索了，慢慢享受个够…这下我们也算是盛会之星的大人物啦。
